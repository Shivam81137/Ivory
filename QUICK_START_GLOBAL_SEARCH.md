## 🎯 Understanding Search Results

### Result Format

```
┌────────────────────────────────────┐
│ LOCAL LIBRARY (If you have it)     │
├────────────────────────────────────┤
│ Song Title                          │
│ Artist · Album                      │
│ [Album Art] [+ Play Button]         │
├────────────────────────────────────┤
│ 🌐 ONLINE RESULTS (Streaming)       │
├────────────────────────────────────┤
│ Song Title                          │
│ Artist · Album · 🎵 FULL | ⏱️ 30s │
│ [Album Art] [+ Play Button]         │
│ (Shows where it's from)             │
└────────────────────────────────────┘
```

### Quality Badges Explained

| Badge | Meaning | Source |
|-------|---------|--------|
| 🎵 **FULL** | Complete song | Deezer / JioSaavn |
| ⏱️ **30s** | 30-second preview | iTunes |
| 🌐 **DEEZER** | Streaming service | Deezer API |
| 🇮🇳 **JIOSAAVN** | Indian music central | JioSaavn API |  
| 🍎 **ITUNES** | Apple Music store | iTunes API |

## ❌ Common Issues & Solutions

### "Search Taking Too Long"
```
Normal:  1-2 seconds
If >5s:  Check internet speed
Fix:     Wait or clear search box
```

### "No Results Found"
```
Try different search:
❌ "i want a song"
✅ "Song Title"

Try exact artist name:
❌ "weekend" 
✅ "The Weeknd"

Try Hindi/native script:
Type in Hindi/Punjabi instead of English
```

### "Can't Play This Stream"
```
This means location restriction
Solutions:
1. Try searching same song again
2. Different version might work
3. Most Deezer songs work globally
4. iTunes shows if region-locked
```

### "Album Art Showing Placeholder"
```
This is normal for:
- Very new songs (not in database yet)
- Indie/independent releases
- Geographically restricted songs

Will auto-fetch after a moment!
```
