# Ivory 🎵

Ivory is a modern, responsive music streaming web application designed to deliver a seamless listening experience. It features a sleek user interface, comprehensive track discovery, and synchronized real-time lyrics, all powered by robust external APIs. 

**Live Demo:** [View Ivory on Vercel](https://your-ivory-deployment-link.vercel.app/)

## Features

* **Rich Music Catalog:** Search and discover music seamlessly using the iTunes Search API.
* **Real-Time Lyrics:** View perfectly synced lyrics for your favorite tracks, powered by the LRCLIB API.
* **Responsive UI:** A beautifully designed interface that works flawlessly across desktop, tablet, and mobile devices.
* **Audio Playback Controls:** Smooth and intuitive media player with play, pause, skip, and volume controls.
* **Modern Deployment:** Lightning-fast hosting and delivery via Vercel.

## Tech Stack

* **Frontend:** React.js / Next.js
* **Backend Integration:** Node.js 
* **APIs:** 
  * [iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/index.html) (Track and metadata retrieval)
  * [LRCLIB](https://lrclib.net/) (Synchronized lyrics)
* **Deployment:** Vercel
